# Языковой паспорт (Language Passport)

Простое и легкое веб-приложение (PWA) для изучения алфавитов различных языков (Турецкий, Украинский, Немецкий, Японский).

## Структура проекта
- `index.html` — главная точка входа.
- `css/style.css` — стили, темы оформления (светлая/темная) и анимации.
- `js/data.js` — данные алфавитов (буквы, транскрипции, подсказки).
- `js/app.js` — основная логика приложения (рендер интерфейса, навигация, переключение тем).
- `icons/` — иконки для PWA.

## Технологии
Проект написан на чистом (Vanilla) HTML, CSS и JavaScript без использования сторонних библиотек.

## Запуск
Достаточно просто открыть файл `index.html` в любом современном браузере. Для работы локально не требуется сборщик или сервер.
