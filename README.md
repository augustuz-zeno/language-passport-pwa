## ✨ Возможности

- **Изучение алфавитов:** Турецкий, Украинский, Немецкий, Японский.
- **Темы оформления:** Поддержка светлой и темной тем.
- **PWA-функционал:** Установка на устройство и оффлайн-доступ.
- **Чистый стек:** Без зависимостей и сторонних библиотек (HTML, CSS, Vanilla JS).

---

## 📂 Структура проекта
```text
├── css/
│ └── style.css # Стили, темы и анимации
├── js/
│ ├── data.js # Данные алфавитов (буквы, транскрипции)
│ └── app.js # Логика UI и навигация
├── icons/ # Иконки PWA
├── index.html # Главная точка входа
└── LICENSE # Лицензия MIT
```

## 🛠 Запуск проекта

Для локальной работы не требуются сборщики и серверы.

1. Клонировать репозиторий:
```bash
   git clone https://github.com/augustuz-zeno/language-passport-pwa.git
```
2. Открыть файл `index.html` в любом браузере.
